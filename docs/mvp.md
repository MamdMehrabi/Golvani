# Golvani — MVP

## Goal

The goal of the MVP is to build a simple social platform that combines short-form public posts with private messaging.

The MVP should validate the core social experience, messaging infrastructure, and overall product architecture before introducing advanced features.

## Core Features

### Social Platform

* User registration and authentication
* User profiles
* Create and publish short-form posts
* Public timeline / feed
* Like posts
* Reply to posts
* Repost content
* Follow and unfollow users

### Messaging

* One-to-one conversations
* Real-time messaging
* Message persistence
* Message delivery status
* Basic offline message handling

## Out of Scope

The following features are not part of the MVP:

* Group chats
* Voice and video calls
* File and media sharing
* Stories
* Live streaming
* Advanced recommendation algorithms
* End-to-end encryption
* P2P communication
* Distributed or decentralized architecture
* Advanced anti-censorship mechanisms

## MVP Success Criteria

The MVP is considered successful when users can:

1. Create an account and manage their profile.
2. Publish and interact with short-form posts.
3. Follow other users and view their content.
4. Communicate privately with other users in real time.
5. Access their social feed and conversations reliably.
6. Continue using the application after temporary connection interruptions.

The MVP should provide a solid foundation for Golvani's future evolution into a scalable and resilient social communication platform.
